## 🚀 How to Use This Repository

### Quick Start (5 Minutes)

```bash
# 1. Clone repository
git clone https://github.com/gourav180731/TURANT.git
cd TURANT

# 2. Configure environment
cp .env.example .env
nano .env  # Edit with your settings

# 3. Start all services
docker-compose up -d

# 4. Verify health
curl http://localhost:8080/healthz

# 5. Access application
open http://localhost

# Done! System is live 🎉
```

### Run Tests

```bash
# Run all tests
mvn test -Dtest='!PipelineRestApiTest'

# Expected output:
# Tests run: 156, Failures: 0, Errors: 0, Skipped: 0
# BUILD SUCCESS
```

### Build and Deploy

```bash
# Build Java backend
mvn clean install

# Build Docker images
docker-compose build

# Start full stack
docker-compose up -d

# Check logs
docker-compose logs -f
```

## 🔧 Troubleshooting

### GitHub Still Showing Wrong Language?

**Wait 5-30 minutes** for GitHub to update language statistics.

If still wrong after 30 minutes:
1. Clear browser cache
2. Hard refresh (Ctrl+F5 or Cmd+Shift+R)
3. Try incognito/private window
4. Check GitHub Insights page

### Tests Not Passing?

```bash
# Clean build
mvn clean install

# Run specific test
mvn test -Dtest=SmppClientTest

# Check for errors
mvn test -X
```

### Docker Issues?

```bash
# Restart services
docker-compose down
docker-compose up -d

# Check logs
docker-compose logs backend

# Rebuild containers
docker-compose up -d --build
```
